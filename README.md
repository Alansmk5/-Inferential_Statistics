# Estadística inferencial para los negocios

Este repositorio contiene tres cuadernos de Google Colab realizados para la clase. En ellos practiqué conceptos básicos de Python y NumPy, y después los apliqué en un ejercicio sobre poblaciones y muestras.

## Contenido de los cuadernos

### INTRODUCCIÓN_A_NUMPY_1.ipynb

Es una introducción a las herramientas que se usan para trabajar con datos. Muestra distintos tipos de datos en Python, cómo crear listas, consultar sus elementos y recorrerlas con ciclos. También explica que las listas no siempre hacen las operaciones matemáticas como podríamos esperar: al sumar dos listas, por ejemplo, sus elementos se juntan.

Después se utiliza **NumPy** para convertir las listas en arreglos. Con ellos sí se pueden sumar o multiplicar los valores elemento por elemento. El cuaderno termina mostrando cómo acomodar los números de un arreglo en **matrices** de diferentes cantidades de filas y columnas.

### TAREA, ESTADISTICA.ipynb

Es una práctica de los temas anteriores. Compara las operaciones con listas normales de Python y con arreglos de NumPy mediante ejemplos sencillos. También crea matrices a partir de un conjunto de 20 números, organizándolos en formatos de 5 × 4 y 10 × 2.

### ESTADISTICA_APUNTE.ipynb

Este cuaderno se enfoca en la idea de **población y muestra**. Primero genera una población de 10,000 números y muestra su distribución en una gráfica. Luego toma 1,000 muestras de 30 datos, calcula la media de cada muestra y grafica los resultados.

Por último, repite el ejercicio con muestras de **5, 30 y 100 datos**. Así se puede observar cómo cambia la distribución de las medias muestrales cuando cambia el tamaño de la muestra. Este ejercicio ayuda a entender por qué el tamaño de una muestra importa al estudiar una población.

## Conclusión y aplicación en mi trabajo

Estos ejercicios me ayudaron a entender cómo organizar datos y por qué una muestra puede servir para conocer mejor un conjunto más grande. También aprendí que el tamaño de la muestra influye en los resultados que obtenemos.

En mi trabajo administrando ventas en **Amazon y Mercado Libre**, puedo aplicar estas ideas para revisar datos como ventas, precios o tiempos de entrega. Por ejemplo, si quiero conocer el tiempo de entrega habitual, puedo analizar una muestra de pedidos y calcular su promedio. Si reviso más pedidos, tendré una idea más clara del comportamiento general y podré tomar mejores decisiones.
